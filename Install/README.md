# Локална инсталација — GoDigital Finance OS (Сметководител)

Овој фолдер го крева **целиот систем локално** на твојот компјутер, како вистински сервер, за да
можеш да го работиш секојдневно пред да го качиме на хостинг. Ги користи **истите податоци** што
веќе ги имаш; кога одиме online, ги пренесуваме на серверот 1:1.

> Работи на Windows со **Docker Desktop**. Ако немаш Docker Desktop — инсталирај го прво од
> https://www.docker.com/products/docker-desktop/ и рестартирај го компјутерот.

---

## 1. Прв пат — инсталација

Отвори **PowerShell** во папката на проектот и изврши:

```powershell
powershell -ExecutionPolicy Bypass -File Install\install.ps1
```

Тоа автоматски:

1. го стартува Docker (ако не работи),
2. го гаси dev стекот за да нема конфликт,
3. создава конфигурација со случајни тајни (`Install\.env.install`),
4. гради и подига: **апликација + worker + база + складиште**,
5. ги применува миграциите,
6. **создава икона „Сметководител" на десктоп**,
7. го отвора системот.

Првото градење трае неколку минути (се презема и се компајлира). Следните палења се брзи.

## 1a. Отворање како апликација (икона на десктоп)

По инсталацијата, на десктоп имаш икона **„Сметководител"**. **Двоен клик** — системот се
отвора во посебен прозорец (како апликација, без терминал и без прелистувач-табови). Ако не е
запален, прво се пали автоматски. За гасење: Start Menu → **„Изгаси Сметководител"**.

Детали: `Install\app\README.md`. За вистински инсталер со чаробник (`Setup.exe`):
`Install\installer\README.md`.

## 2. Секојдневна употреба

| Сакам да…                    | Команда                                                          |
| ---------------------------- | ---------------------------------------------------------------- |
| Го **вклучам** системот      | `powershell -ExecutionPolicy Bypass -File Install\start.ps1`     |
| Го **исклучам** системот     | `powershell -ExecutionPolicy Bypass -File Install\stop.ps1`      |
| Направам **бекап** на базата | `powershell -ExecutionPolicy Bypass -File Install\backup-db.ps1` |
| Видам **логови** (грешки)    | `powershell -ExecutionPolicy Bypass -File Install\logs.ps1 web`  |
| Земам **нов код** и ажурирам | `powershell -ExecutionPolicy Bypass -File Install\update.ps1`    |

Податоците остануваат зачувани и по гасење и по рестарт на компјутерот.

> 💡 Совет: направи `.bat` кратенки на десктоп што ги повикуваат овие, за да не куцаш команди.

## 3. Важно за безбедност (прочитај!)

- **Не се праќа никаква е-пошта** додека работиш локално. Gmail е намерно исклучен, па нема
  ризик случајно да пратиш фактура или потсетник на реален клиент.
- Затоа и **автоматскиот увоз од Gmail не работи** локално — изводите и Meta сметките ги
  **внесуваш рачно преку екранот „Увоз"** (како досега).
- Cron-от (месечно задолжување W1, курс W7) работи, но само создава интерни нацрти — не праќа ништо
  надвор.

## 4. „Истата база" — како функционира

Локалниот систем ја користи **истата Docker податочна единица** (`smetkovoditel_db_data`) што веќе
ја имаш. Сè што внесуваш локално се трупа таму.

Кога одиме на хостинг:

1. Изврши `Install\export-db.ps1` → создава `.sql` датотека во `Install\exports\`.
2. Таа датотека се пренесува на серверот и се внесува во продукциската база.
3. Целата твоја локална работа преминува 1:1 online.

---

## 5. Пренос на хостинг (go-live, накратко)

1. Локално: `Install\export-db.ps1` → земи ја датотеката од `Install\exports\`.
2. На серверот: подигни го `docker-compose.prod.yml`, изврши `prisma migrate deploy`.
3. Внеси го извозот во продукциската база:
   ```bash
   cat smetko-golive-*.sql | docker compose -f docker-compose.prod.yml exec -T db psql -U <user> -d <db>
   ```
4. Провери и продолжи со `scripts/deploy.sh` за понатамошни ажурирања.

Деталите се во `_docs/deployment/production.md`.

## 6. Ако нешто не работи

| Симптом                   | Што да направиш                                                         |
| ------------------------- | ----------------------------------------------------------------------- |
| „Docker не е најден"      | Инсталирај/отвори Docker Desktop, почекај да стартува, пробај повторно. |
| Апликацијата не се отвора | `Install\logs.ps1 web` — погледни ги грешките.                          |
| Порт 3000 зафатен         | Затвори што го користи 3000 (друг проект), па `Install\start.ps1`.      |
| Сакам да почнам од чисто  | Јави се — не бриши го volume-от сам (ги содржи реалните податоци).      |

| ---------------------------- | ----------------------------------------------------- |
| `install.ps1`                | Прва инсталација (еднаш).                             |

| `logs.ps1`                   | Преглед на логови по сервис.                          |
| `docker-compose.install.yml` | Дефиниција на локалниот стек.                         |
| `env.install.example`        | Примерок конфигурација (се копира во `.env.install`). |
| `_common.ps1`                | Заеднички помошни функции (не се вика директно).      |
