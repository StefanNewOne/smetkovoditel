# `Setup.exe` инсталер (дел C — чаробник за инсталација)

Ова прави вистински **Windows инсталер со чаробник** (`Смет-Setup.exe`) што:

- проверува дали има **Docker Desktop** (предупредува ако нема),
- ги создава **десктоп + Start Menu** иконите („Сметководител" + „Изгаси Сметководител"),
- по избор **гради и подига** го системот на крајот (штиклирано поле),
- додава **деинсталер** (Control Panel → Programs) што ги отстранува иконите.

> Делот **B** (`Install\app\`) веќе го дава целото „како апликација" искуство и **работи веднаш**.
> Овој `Setup.exe` е дополнителна углазба за оние што сакаат класична инсталација со чаробник.

## Како да го направиш `Setup.exe` (еднаш)

1. Инсталирај **Inno Setup** (бесплатен): https://jrsoftware.org/isinfo.php
2. Отвори го `Install\installer\smetkovoditel.iss` во **Inno Setup Compiler** и притисни **Compile**
   (или во терминал: `iscc Install\installer\smetkovoditel.iss`).
3. Готовиот инсталер е во `Install\installer\dist\Смет-Setup.exe`.

## Употреба

Двоен клик на `Смет-Setup.exe` → чаробникот те води. Потврди ја папката на проектот (каде што е
`Install\`), избери дали да се изгради веднаш, заврши. Иконата „Сметководител" се појавува на
десктоп.

## Забелешки

- Inno Setup е Unicode, па кириличните имиња на иконите работат природно овде (за разлика од рачното
  создавање преку `WScript.Shell`).
- Инсталерот **не го преместува кодот** — системот се гради од оваа папка (Docker build context),
  па иконите покажуваат кон `Install\app\` во проектот.
- `dist\` не се commit-ира (види `.gitignore`).
