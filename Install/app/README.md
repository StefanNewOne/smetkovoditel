# Сметководител како апликација (десктоп икона)

Овој фолдер го прави системот да се отвора **како апликација** — двоен клик на икона, без терминал.

## Што прави

- **Десктоп икона „Сметководител"** → отвора посебен прозорец (без адресна лента/табови,
  Edge „app mode", изолиран профил, своја икона во taskbar). Ако системот не е запален, прво го
  пали автоматски (со кратко „Се подигнува…" известување), па го отвора.
- **Start Menu → Сметководител** → истата икона + **„Изгаси Сметководител"** за гасење.

Иконите се создаваат автоматски при `Install\install.ps1`. Ако сакаш рачно да ги (пре)создадеш:

```powershell
powershell -ExecutionPolicy Bypass -File Install\app\install-shortcuts.ps1
```

## Датотеки

| Датотека                            | Улога                                                                    |
| ----------------------------------- | ------------------------------------------------------------------------ |
| `launch-app.vbs` / `launch-app.ps1` | Палење + отворање на апликацискиот прозорец (скриено, без терминал).     |
| `stop-app.vbs` / `stop-app.ps1`     | Гасење.                                                                  |
| `install-shortcuts.ps1`             | Создава десктоп + Start Menu икони (кирилични имиња).                    |
| `make-icon.ps1`                     | Ја генерира `smetkovoditel.ico` од брендот (се вклучува веќе создадена). |
| `smetkovoditel.ico`                 | Икона за кратенките.                                                     |

## Забелешки

- Docker Desktop сепак е потребен (моторот). Иконата автоматски го стартува ако не работи.
- Прозорецот користи посебен Edge профил (`%LOCALAPPDATA%\Smetkovoditel\browser-profile`) — не се
  меша со твоето обично сурфање.
- За вистински инсталер со чаробник (`Setup.exe`), види `Install\installer\`.
